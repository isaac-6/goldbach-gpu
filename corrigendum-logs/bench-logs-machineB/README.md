# Machine B (multi-GPU)

The figures in `results.csv` were **transcribed from the session terminal**, not
captured to file. The node was a rented ephemeral pod that no longer exists, so
the raw per-run output cannot be recovered. Every other directory under
`corrigendum-logs/` is machine-captured; this one is not, and is correspondingly
weaker evidence.

See "Provenance notes" in [`../README.md`](../README.md) for the full account,
including why only the 1- and 2-GPU configurations were exercised on a four-GPU
node. The environment is in `environment.txt`.
